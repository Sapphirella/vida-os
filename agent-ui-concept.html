Agent 界面重设计

现有 Agent 界面在桌面端能用，但信息密度、状态可见性和移动端可达性都有明显问题。 下面是逐条问题诊断，以及一版完整重设计方案 —— 会话列表与聊天主界面两屏都在。

方案只改 Agent 模块的视觉与交互，不动全局主题系统、不动其他页面。

一、当前界面的六个问题

按严重程度排序。前两条是功能性缺陷，不是审美偏好问题。

1

移动端操作按钮永远点不到（功能缺陷）
消息的复制 / 重新生成 / 删除都写成 opacity-0 group-hover:opacity-100。 桌面端鼠标悬停才浮现，但手机没有 hover —— 这三个功能在移动端等于不存在。

2

用户消息的操作区在气泡内部且默认透明
时间戳和按钮塞在酒红气泡里、默认 opacity-0。低对比 + 位置别扭，两头不讨好。

3

顶栏 6 个控件挤在 44px 内，密度过高
返回、标题、API 徽章、记忆馆、导出、配置。记忆馆和配置还都打开同一个面板，功能重复。

4

Agent 在聊天页没有身份标识
会话列表页有机器人头像，进了聊天页就消失。用户对话时不知道"谁在说话"。

5

消息缺少扫描锚点，长会话难定位
左侧回复是裸文字、右侧气泡是酒红块，两种形态宽度上限还不一样（92% / 86%），节奏被打散。

6

流式状态信息量为零
正在生成时只有三个弹跳点，用户不知道它在读资料、在写文章、还是在等网络。

二、聊天主界面 · 新设计

核心思路：把"谁在说"和"什么时候说的"变成常驻信息，而不是 hover 才出现； 顶栏做减法，把低频操作收进一个溢出菜单。

四、设计规格

全部沿用暗夜书房色板，与全局主题联动，日间/猩红自动适配。

元素规格说明
消息头像 26pt 圆形 用户=玫瑰木实底；Agent=玫瑰木→暗酒红渐变，唯一的渐变元素，用于区分身份
姓名标签 12pt / 500 常驻显示，不做 hover 显隐
时间戳 9.5pt mono 紧跟姓名，40% 透明度后退为背景信息
用户气泡 圆角 13/13/4/13 右下角收窄形成指向感，文字用 #EFD9D9 保证对比
Agent 正文 14pt / 1.68 不用气泡，用留白和头像分隔 —— 长回复读起来更轻
操作区 40% 常态，85% 悬停 关键改动：不再用 opacity-0，移动端始终可见
系统提示 居中胶囊 9.5pt mono，用于"已加载 N 篇资料"这类上下文
流式状态 旋转图标 + 文字 替代三弹跳点，说明在做什么（检索 / 撰写 / 等待）
输入区 圆角 14pt 下方一行快捷键提示，降低功能发现成本
顶栏 46pt 高 · 3 控件 返回 / 标题+元信息 / 溢出菜单。导出与配置收进菜单
一个功能修复：操作区从 opacity-0 group-hover:opacity-100 改为常态 40% 透明度。这不只是审美调整 —— 它修复了移动端完全无法删除或复制消息的实际缺陷。

这版方案可以直接落到 AgentPage.tsx 和 AgentChatView.tsx。 你确认方向后我再动代码 —— 布局以外的部分（滚动逻辑、流式、附件、面板）都会原样保留。
