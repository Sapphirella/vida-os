# VidaOS

> 你的私密生活记录空间 —— 采用 iOS 原生液态玻璃风格设计，离线本地运行，数据完全属于你自己。

![VidaOS Preview](preview-placeholder)

---

## 简介

**VidaOS** 是一款面向个人用户的本地博客系统，灵感来源于 iOS 液态玻璃（Liquid Glass）设计语言。它不依赖任何服务器，所有数据存储在浏览器的本地存储空间中，让你能够安心记录生活点滴、上传照片、写下吐槽，而无需担心隐私泄露。

### 设计灵感

- **iOS Liquid Glass**：采用 `backdrop-filter` 实现的磨砂玻璃效果，半透明材质、柔和阴影与大圆角，营造通透纯净的界面质感
- **参考项目**：借鉴 [XinghuisamaBlogs](https://github.com/heiehiehi/XinghuisamaBlogs) 的毛玻璃博客设计理念

---

## 功能特性

### 核心功能
- **三种内容类型**：日记、照片、吐槽，满足不同场景的记录需求
- **Markdown 编辑与预览**：支持富文本编辑，实时预览渲染效果
- **图片上传**：支持拖拽和点击上传，本地存储 Base64 编码
- **标签管理**：为每篇文章添加多个标签，方便分类整理
- **时间线视图**：按日期纵览所有记录，清晰回溯生活轨迹
- **图集视图**：以网格形式展示所有上传的照片

### 数据管理
- **本地持久化**：所有数据使用 `localStorage` 存储，离线可用
- **导出 JSON**：完整备份所有文章、图片、标签数据
- **导出 TXT**：导出为纯文本合集，方便阅读与备份
- **导出 Markdown**：导出为 Markdown 格式，便于迁移到其他平台
- **导出 PDF**：使用 html2pdf.js 生成精美 PDF 文档
- **导入数据**：支持从 JSON / TXT / Markdown 文件恢复数据

### 界面设计
- **液态玻璃材质**：全界面采用磨砂玻璃质感，通透且高级
- **响应式布局**：完美适配桌面端与移动端
- **流畅动效**：优雅的悬停、点击与过渡动画
- **实时时钟**：首页显示当前日期与时间
- **统计概览**：文章数、照片数、标签数、记录天数一目了然

## 安装使用

### 方法一：直接打开（推荐）

1. 确保你已克隆或下载了本项目到本地
2. 使用现代浏览器（Chrome / Safari / Edge / Firefox）打开 `index.html` 文件
3. 开始使用！

```bash
# 进入项目目录
cd /Users/amarisgo/Documents/VidaOS

# 用浏览器打开
open index.html
```

### 方法二：本地服务器（可选）

如果你需要更好的文件访问权限（如某些浏览器的图片上传限制）：

```bash
cd /Users/amarisgo/Documents/VidaOS

# Python 3
python -m http.server 8080

# 或 Node.js
npx serve .

# 或 PHP
php -S localhost:8080
```

然后在浏览器中访问 `http://localhost:8080`

### 方法三：部署到静态托管

将项目目录中的文件上传到任何静态托管服务即可：
- GitHub Pages
- Vercel
- Netlify
- 阿里云 OSS / 腾讯云 COS
- 你自己的 Web 服务器

## 使用指南

### 创建记录

1. 在首页点击「写日记」「发照片」或「吐槽」按钮
2. 填写标题（可选）和内容
3. 点击「编辑」/「预览」切换 Markdown 编辑和预览模式
4. 点击上传区域添加照片（支持拖拽）
5. 在标签栏输入标签，按空格或回车确认
6. 选择内容类型，点击「保存」

### 浏览记录

- **主页**：查看最近的文章列表
- **时间线**：按日期纵向浏览所有记录
- **标签**：查看所有标签，点击标签筛选相关文章
- **图集**：以网格形式浏览所有照片

### 编辑与删除

1. 点击任意文章卡片打开详情
2. 点击右上角的编辑或删除图标
3. 编辑后保存，或确认删除

### 数据备份与恢复

**导出数据**：
1. 进入「设置」页面
2. 选择导出格式（JSON / TXT / Markdown / PDF）
3. 文件将自动下载到本地

**导入数据**：
1. 点击首页「导入」按钮，或进入设置页「导入数据」
2. 选择 `.json` / `.txt` / `.md` 文件
3. 数据将自动合并到现有记录中

**清空数据**：
- 在设置页点击「清空所有数据」，此操作不可恢复，建议先导出备份

## 隐私说明

- **全部数据存储在本地**：使用 `localStorage`，不上传任何服务器
- **图片使用 Base64 编码**：直接嵌入在数据中，不依赖外部链接
- **无追踪、无分析、无广告**
- **完全离线可用**：不需要网络连接

---

## 已知限制

1. **存储容量**：`localStorage` 通常限制在 5-10MB，大量高分辨率图片可能超出容量
2. **浏览器隔离**：不同浏览器/设备之间的数据不互通
3. **清除风险**：清除浏览器缓存会导致数据丢失（请务必定期导出备份）
4. **无多用户支持**：设计为单用户本地使用
